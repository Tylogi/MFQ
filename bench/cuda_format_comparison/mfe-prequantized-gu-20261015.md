# 独立 hidden 量化路径的 GU 专用核

承接 `mfe-parity-read-20261015.md`；保留压缩权重、原点积/激活次序、已有 E8 奇偶位及只读码本候选、缓存同步和全部此前优化。

生产默认在 GU 后独立启动 hidden 量化核，GU 的 `completion` 已清空。原 GU 仍读取 Gate、Up、Down 三份 184 B 描述表，保留原子完成计数及组内量化分支，并使用一次 CTA 同步广播 kind。新 `mfe_ffn_gu_prequantized.cuh` 仅在这项明确条件下使用：

- 保持 8 warp、每个投影每 warp 两行、相同格式掩码和算术顺序，仅读取 Gate/Up 两份描述表。
- `kinds`、设备 `aborted` 和设备描述表在当前核期间不变，各 warp lane 0 独立读取分类再广播，减少一次 CTA 同步。CPU 取消仍由后续原有必经核检查。
- 删除 GU 内不再执行的 completion/Down 逻辑，保留后续生产 hidden 量化节点。
- 将路由和共享专家的实际行块连续排列。宽度不同时不再提交只会返回的多余块；本次 S2-L 六层探针的两种宽度相同，880 块仍为 880 块，不能把此一般性布局变化宣称为本模型的块数节省。

`MFQ_MFE_GU_PREQUANTIZED=0` 可选用此前的 GU；有 completion 的路径保留原核。该候选目前沿用 parity GU 的范围，默认 M1 标准 compact GU；显式开启 parity GU 才会进入 M2/6 标准 GU，不影响分组 GU 分派。

初版矩形网格经过 864 次变化输入/重复及无效路由的图重放比对，逐字节一致；memcheck 125.41 秒、0 errors。更改为连续行块后的版本重新通过同样 864 项比对，synccheck 19.49 秒、0 errors。额外将共享专家放到末尾，并更换缓存地址、清零旧数据的部分 GU 检查通过，memcheck 6.00 秒、0 errors。84 项宽路由/部分 GU 的缓存增长、重复路由和取消检查通过。

资源及静态指令保存于 `workspace/local-server/prequantized-gu-kernel-resources-20261015.json`。初版新/旧 GU 均为 64 registers、0 stack、0 local；shared 712→416 B，未因此提升寄存器限制的理论驻留数。连续行块最终资源以该 JSON 为准。

独立计时期间模型服务卸载；没有重跑旧配置。新初版完整 FFN（含共享、缓存驻留、prepare、真实生产 hidden 量化调度）109.0773 μs/层；连续行块版本 109.9253 μs/层，均为 1056 节点/96 FFN。较旧共享 Gate 融合测量 106.6880 μs 没有显示微基准收益；之间也叠加了 E8 和准备同步变化，不能将差值独立归因于新 GU。

上述结果不替代整模 API。新构建清单 `cache-prequantized-gu-api-build-20261015.json` 记录源码和运行文件 SHA256；整模只复用保存的 68.5292 API 参考，并检查新 GU、奇偶位、准备同步及共享 Gate 的实际启用日志。

## 仅传输分区的 hidden 量化融合

新的 `mfe_ffn_compact_transferred_fused()` 只用于缓存分派、M1、有效 completion、标准 compact GU，复用已有完成计数式 GU 量化。驻留 GU 保持独立量化；传输 GU 从两个节点变为一个，空传输也减少一次无用量化启动。保留早到 GU、部分 Down 驻留、取消和 Down 合并的原有顺序。`MFQ_MFE_TRANSFER_HIDDEN_FUSED=0` 可关闭。通过独立模块和 C++ 启动器接入，避免重编译通用 MFE 大模板。

新增真实冷专家模式 7/8：每层明确检查五个路由在 transfer 分区执行，另有完整缓存/初级驻留专家；同时保留模式 5/6 的早到 GU。最初模拟 CPU 计划将完整缓存命中错误标为 transfer，分类断言失败，已修正测试计划并保留首次失败日志；未将空执行当作验证通过。修正后，M1/2/6、六层、共享/无共享、变化输入及重复/无效路由的 864 项比较逐字节一致。M1 修改路径在 memcheck 下再验 288 项并确认 24 组五冷专家分类，22.27 秒、0 errors；84 项流水取消及缓存增长检查通过。
